How it works

this website uses R6Data's Api to get your statistics, that's why you need an api key. It can't be hosted locally because fetches don't work, so the only place you can use this is on http://eurpps.com, which is a site that I hosted and put a proxy in to avoid CORS issues. It works by getting the data in the form of a json file and then parsing it to get the specific data for each statistic that is measured.
